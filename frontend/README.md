# Basketball Analytics Frontend

React + Vite frontend for the basketball analytics app.

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

The dev server runs on http://localhost:5173 and proxies API requests to the backend at http://localhost:8000.

## Build

```bash
npm run build
```

## Test

```bash
npm test
```

## Lint

```bash
npm run lint
```
